# בדיקת האתר · 24 בנובמבר 2026

הבדיקות בוצעו ב־Google Chrome מול האתר המקומי. צילומי המסך במאגר משקפים את הגרסה הזו.

- בשלושת השירותים נבדקה פתיחת הדוגמה והגעה לטופס עם סוג הפנייה המתאים.
- ברוחבי מסך של 320, 390, 660, 768, 1024 ו־1440 פיקסלים נבדק שאין גלישה אופקית.
- נבדקו קישור הדילוג באמצעות המקלדת, פתיחת תשובה באמצעות Enter והיעדים של הקישורים הפנימיים.
- כשהרצת JavaScript כבויה אפשר לפתוח דוגמה, לעבור לטופס ולהגיע לכפתור השליחה.
- נבדקו חסימת מספר טלפון שגוי, שמירת הפרטים והצגת נוסח לאינסטגרם אחרי כשל, ואיפוס הטופס אחרי אישור שליחה. התגובות מ־FormSubmit הודמו בדפדפן.
- עם תשובת שרת מדומה נבדקו הופעת עבודה מאומתת וקישור הניווט שלה והסרתם לאחר פקיעת האימות.
- 25 בדיקות Node.js של אימות הפרויקטים עברו.
