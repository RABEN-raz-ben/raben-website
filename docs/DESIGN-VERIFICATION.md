# בדיקת האתר · 24 בנובמבר 2026

הבדיקות בוצעו ב־Google Chrome מול האתר המקומי. צילומי המסך במאגר משקפים את הגרסה הזו.

- בשמונה דוגמאות נבדקו טעינת הצילום, הפעלת המסך, שינוי התוצאה ושמירת המיקוד. נבדקו שלושת המסננים, החזרה מהפריט האחרון לראשון, קישור ישיר והעתקת הקישור.
- נבדקו מעבר אוטומטי אחרי שמונה שניות, עצירה מחוץ למסך ובלשונית מוסתרת, הפעלה מחדש, הפחתת תנועה ושחזור בחירה ברענון.
- נבדקו עריכת הקשר הדוגמה, הסרתו ושמירת ההודעה האישית. ניסיון שנכשל וניסיון חוזר מוצלח נבדקו באמצעות תשובות מדומות, כולל הפרטים שהועברו לטופס ולנוסח האינסטגרם.
- בבדיקה עם צילום מעוכב היה אפשר לבחור תאריך ולקבל סיכום לפני שהצילום הגיע. גם כשבקשות הצילום נכשלו, המסך וקישור הפנייה פעלו.
- ב־390 וב־1440 פיקסלים נמדד אותו גובה של צמד הצילום והמסך בכל שמונה הדוגמאות. בבדיקת axe-core של שמונת מצבי הגלריה לא נמצאו הפרות בכללי WCAG A/AA שנבדקו.
- ברוחבי מסך של 320, 390, 660, 768, 1024 ו־1440 פיקסלים נבדק שאין גלישה אופקית.
- בתצוגת נייד של 390×844 פיקסלים כפתור בקשת השיחה גלוי במסך הראשון. טלפון הוא שדה החובה היחיד.
- נבדקו קישור הדילוג באמצעות המקלדת, פתיחת תשובה באמצעות Enter והיעדים של הקישורים הפנימיים.
- כשהרצת JavaScript כבויה מוצגת דוגמת הסדנה. אפשר לפתוח גם את רשימת שבעת הרעיונות הנוספים ולעבור ממנה לטופס.
- נבדקו הודעת שגיאה ליד מספר חסר או שגוי, שיוכה לשדה והעברת המיקוד אליו. לחיצה כפולה יצרה בקשה אחת. לאחר כשל נשמרו הפרטים לניסיון חוזר ולהעתקה לאינסטגרם. אחרי אישור שליחה הטופס התאפס וההצלחה הוצגה באזור סטטוס נגיש. התגובות מ־FormSubmit הודמו בדפדפן.
- עם תשובת שרת מדומה נבדקו הופעת עבודה מאומתת וקישור הניווט שלה והסרתם לאחר פקיעת האימות.
- בהגדלה ל־200% נבדקו הזנת טלפון ופרטי הרשות. בבדיקת axe-core של מסך הכניסה בכרום לא נמצאו הפרות בכללי WCAG A/AA שנבדקו. נבדקו גם שמות הבקרים בעץ הנגישות ואזורים דינמיים להודעות שגיאה והצלחה.
- 25 בדיקות Node.js של אימות הפרויקטים עברו.
